## 2. Architecture & Design Patterns

### SurfSense
- **Clean separation**: Python FastAPI backend + Next.js frontend as independent services
- **Deep Agent architecture**: Uses LangChain's Deep Agents with planning, subagents, and sandbox execution
- **Celery** for background task processing (connector syncing, document indexing, podcast generation)
- **Mature RBAC**: Owner / Admin / Editor / Viewer roles with real-time collaboration
- **MCP connector support** — can integrate with any MCP-compatible tool server

### DigiClassroom Pro (Upgraded)
- **Next.js 15 monolith** with tRPC for type-safe API
- **Dual agent architecture** (major upgrade):
  - **Legacy agents** = standalone TypeScript classes implementing [IAgent](file:///J:/Apps/DigiClassroomPro/src/lib/agents/core/base-agent.ts#62-83) via [BaseAgent](file:///J:/Apps/DigiClassroomPro/src/lib/agents/core/base-agent.ts#109-244)
  - **LangGraph agents** = `StateGraph`-based, built via shared `BaseGraphFactory`
  - Feature flags toggle between legacy and LangGraph per-agent
- **Enterprise DI container** with singleton/transient/scoped lifecycles, circular dependency detection, and health checks
- **BullMQ** for background job processing (document processing, connector sync, notifications, audio generation)
- **Redis caching** with graceful degradation (graph answers cached, app continues if Redis is unavailable)

> **Verdict (Architecture):** SurfSense remains architecturally cleaner (purpose-built services). DigiClassroom Pro has made a **massive leap** with `BaseGraphFactory`, DI container, and feature flag infrastructure — the dual-factory LLM pattern is genuinely well-designed. The monolith is better organized now but still carries migration debt.

## 3. LLM Provider Support

### SurfSense
- **100+ LLMs** via LiteLLM Router — any OpenAI-compatible API works out of the box
- **6000+ embedding models** supported
- Per-search-space LLM configuration
- **Zero code changes** to switch providers

### DigiClassroom Pro (Upgraded — formerly OpenAI-only)
- **5 providers**: OpenAI, Anthropic (Claude), Google (Gemini), Groq, Ollama
- **Two factory pattern**:
  - [LLMFactory](file:///J:/Apps/DigiClassroomPro/src/lib/agents/core/llm/llm-factory.ts) → returns `ILLMProvider` for legacy agents
  - [LangChainModelFactory](file:///J:/Apps/DigiClassroomPro/src/lib/llm/LangChainModelFactory.ts) → returns `BaseChatModel` for LangGraph nodes
- Feature flag `archMultiProviderLLM` gates multi-provider access (safe fallback to OpenAI)
- Model-level cache with `{provider}:{temperature}:{streaming}` key
- **Provider-specific configs** via environment variables

> **Verdict:** SurfSense is still **far superior** in breadth (100+ vs 5 providers). DigiClassroom Pro's upgrade from 1 → 5 providers is significant, and the dual-factory pattern is architecturally sound. The feature flag gating is a nice safety mechanism.

## 4. Agent System

### SurfSense
- **Deep Agent architecture**: Single configurable agent with dynamic tool building (LangChain Deep Agents)
- Tools: Knowledge base search, podcast generation, image generation, web crawling, memory save/recall, report generation, sandbox execution
- MCP tool integration for arbitrary external tools
- **55KB system prompt** (!) — one of the most detailed agent system prompts in open source

### DigiClassroom Pro (Upgraded — formerly ad-hoc agents)
- **12 LangGraph-migrated agents**, each split into [Graph](file:///J:/Apps/DigiClassroomPro/src/lib/agents/graph/registry.ts#44-60) + `Node` files:
  - StudyTips, CbseAnswerFormatter, ConversationalLearning, ExamPreparation, TopicExplanation, SelfStudyBuddy, DoubtClearing, HomeworkHelp, ConstrainedGeneration, EnhancedSynthesis, Citation, SourceValidation
- **Shared graph infrastructure** via [BaseGraphFactory](file:///J:/Apps/DigiClassroomPro/src/lib/agents/graph/BaseGraphFactory.ts):
  - Flow: `START → set_agent_name → retrieve → validate_scope → generate → format_citations → trace → END`
  - Conditional edges for scope violation and fallback (up to 3 levels)
  - Every agent shares: retrieval, scope validation, citation formatting, Langfuse tracing, and fallback nodes
- **Base agent framework**:
  - Abstract [BaseAgent](file:///J:/Apps/DigiClassroomPro/src/lib/agents/core/base-agent.ts) with `executeWithTracing()` for Langfuse instrumentation
  - 5 core services injected: Retrieval, Citation, ScopeValidation, Bilingual, CognitiveLevel
  - Streaming support via `AsyncGenerator<string>`
- **Graph Registry** with lazy loading and feature-flagged activation per agent
- **Agent state** via `TutorGraphState` with 20+ annotated fields (student context, retrieval state, quality metrics, token usage, A/B variant)

> **Verdict:** This is where DigiClassroom Pro's upgrade is **most dramatic**. The move from ad-hoc agent files to `BaseGraphFactory` with shared infrastructure nodes is a textbook-correct LangGraph implementation. SurfSense's Deep Agent is more flexible for general purposes; DigiClassroom's graph system is superior for domain-specific orchestration with built-in scope validation, citation formatting, and multi-level fallback.

## 5. Retrieval & RAG Pipeline

### SurfSense
- Hybrid search: Semantic (pgvector cosine) + Full Text (PostgreSQL `tsvector`) with RRF
- Hierarchical Indices for document organization
- Optional reranking via `rerankers` library
- **Clean**: ~358 lines for the entire retrieval module

### DigiClassroom Pro (Upgraded)
- **Enhanced Contextual RAG Pipeline** (520 lines) — role-aware retrieval:
  - Board-level filtering (CBSE/ICSE)
  - Grade-level flexibility per user role
  - Subject-specific + interdisciplinary filters
  - Pedagogical context filters (learning style, complexity)
  - **Dynamic score thresholds** based on student profile
- **Visualization Generator** (1,038 lines) — auto-generates educational visualizations:
  - Comparison tables, concept maps (Mermaid), flowcharts, timelines, hierarchical trees
  - **ECharts integration** for bar/pie/line charts
  - On-demand detection from query keywords
  - Fallback generation when LLM fails
- **Response Enhancement Pipeline** (466 lines):
  - Academic tone conversion, CBSE answer formatting
  - Exam strategy integration, memory aid generation
  - Quality metrics (exam readiness score, word count improvement)
  - Class-level readability adaptation

> **Verdict:** DigiClassroom Pro's retrieval is now genuinely enterprise-grade for education. The role-aware filtering and visualization generator are unique differentiators. SurfSense remains more broadly applicable.

## 6. Observability & Production Hardening

### SurfSense
- Task logging service — records connector sync and document processing events
- CI/CD with GitHub Actions (code quality + Docker build workflows)
- `.pre-commit-config.yaml` with code quality checks

### DigiClassroom Pro (Upgraded — formerly minimal)
- **Langfuse tracing** integrated into every agent via `executeWithTracing()`:
  - Session traces with userId, query, subject, grade
  - Generation span recording with latency
  - **Citation quality scoring** (page number precision, citation count, content length)
- **Startup Performance Monitor** (270 lines):
  - Server-side: Phase tracking, memory usage, performance recommendations
  - Browser-side: TTFB, FCP, LCP metrics via `PerformanceObserver`
  - Status classification: Excellent / Good / Needs Improvement / Critical
- **Rate Limiter** (308 lines):
  - Per-endpoint-type limits (AI: 20/15min, General: 100/15min, Batch: 5/hr, Export: 10/hr)
  - Cost-per-request tracking with savings estimation
  - Rate limit stats and admin reset functions
- **A/B Testing Framework**:
  - [Traffic Splitter](file:///J:/Apps/DigiClassroomPro/src/lib/experiments/traffic-splitter.ts) (322 lines): Consistent hash-based user assignment with database persistence
  - [Embedding A/B Test](file:///J:/Apps/DigiClassroomPro/src/lib/experiments/embedding-ab-test.ts): text-embedding-3-large vs text-embedding-3-small comparison
  - [4 experiment templates](file:///J:/Apps/DigiClassroomPro/src/lib/experiments/templates): chunk count, embedding model, prompt variation, retrieval strategy
- **Feature Flags System** (360 lines):
  - 35+ feature flags with environment-based toggle
  - [isFeatureEnabledForUser()](file:///J:/Apps/DigiClassroomPro/src/lib/config/feature-flags.ts#163-190) — percentage-based rollout with consistent hashing
  - React hook [useFeatureFlag()](file:///J:/Apps/DigiClassroomPro/src/lib/config/feature-flags.ts#294-307) for client-side checks
  - Gradual rollout strategy (10% → 50% → 100%)

> **Verdict:** DigiClassroom Pro now **massively exceeds** SurfSense in observability. Langfuse tracing, citation quality scoring, startup monitoring, rate limiting, A/B testing, and feature flags constitute enterprise-grade observability that the previous version completely lacked.

## 7. Infrastructure & DevOps

### SurfSense
- Docker Compose for development and production
- Celery + Redis for background tasks
- PostgreSQL + pgvector (single database)
- All-in-one Docker image available
- GitHub Actions CI/CD pipeline

### DigiClassroom Pro (Upgraded)
- Docker Compose (dev + production) + **Kubernetes manifests**
- **BullMQ + Redis** for background jobs (4 queue types):
  - Document processing (3 retries, exponential backoff)
  - Connector sync (3 retries)
  - Notifications (3 retries)
  - Audio generation (2 retries, keep last 100 completed)
- **DI Container**: Singleton/Transient/Scoped lifecycles, circular dependency detection, health metadata
- **Redis caching** with graceful degradation — app continues without cache
- MySQL + Qdrant (separate vector DB) + Redis
- Jest test infrastructure with golden test configs

> **Verdict:** Both have solid infrastructure. SurfSense's simpler stack (PostgreSQL-native) reduces operational overhead. DigiClassroom Pro has more moving parts (MySQL + Qdrant + Redis) but now manages them properly with BullMQ, DI, and graceful degradation.
