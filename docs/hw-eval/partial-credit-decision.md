# Partial credit: what should a right idea with one wrong detail earn?

**For two subject teachers. About 5 minutes. / दो विषय-शिक्षकों के लिए। लगभग 5 मिनट।**

When a student writes the right idea for a key point but gets one detail wrong (a number, a name, an example), a marker must decide how many of that point's marks to give. The answer key does not say, and the AI marking cannot guess it for you. The table shows real answers (written by a program, not by students) and the marks each rule would give. All key points here are worth 1 mark.

जब विद्यार्थी किसी मुख्य बिंदु का सही विचार लिखता है पर एक बात (संख्या, नाम, उदाहरण) ग़लत लिखता है, तो जाँचने वाले को तय करना होता है कि उस बिंदु के कितने अंक दिए जाएँ। उत्तर-कुंजी यह नहीं बताती, और AI अपने आप यह तय नहीं कर सकता। नीचे असली जैसे उत्तर और हर नियम से मिलने वाले अंक हैं (उत्तर प्रोग्राम ने लिखे हैं, विद्यार्थियों ने नहीं)। यहाँ हर बिंदु 1 अंक का है।

**zero** = no marks for that point · **half** = half the point's marks, rounded down to a half mark (a 1-mark point gets 0.5) · **full** = all the point's marks.  
**zero** = उस बिंदु के 0 अंक · **half** = बिंदु के आधे अंक (आधे अंक की इकाई में नीचे की ओर) · **full** = पूरे अंक।

**The question / प्रश्न**

**When an answer has the right idea but exactly ONE wrong detail (examples 1–4 and 6–8), how many of that key point's marks should it get: none (zero), half, or all (full)? If the answer is different for a subject (for example Hindi or Science), name the subject and the rule.**

**जब उत्तर में सही विचार हो पर ठीक एक बात ग़लत हो (उदाहरण 1–4 और 6–8), तो उस मुख्य बिंदु के कितने अंक मिलने चाहिए: कोई नहीं (zero), आधे (half) या पूरे (full)? यदि किसी विषय (जैसे हिंदी या विज्ञान) के लिए उत्तर अलग हो, तो विषय और नियम का नाम लिखें।**
